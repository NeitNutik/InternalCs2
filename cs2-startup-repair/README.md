## Проверка бинарников

SHA256 client.dll: 99a6720b29d8b477d55f0a2d7fd4333b5df13f354ba723804e996bead1231aa8

InputGlobal: уникальное совпадение RVA 0xEECDA, RIP destination 0x2569E30.
AnglesMember: уникальное совпадение RVA 0xB54D5B, operand displacement 0x688.
Сумма для локального слота: RVA 0x256A4B8. Наличие совпадения и инструкции подтверждено; поведение записи углов в игре не проверено. Это не восстановление subtick/usercmd ABI.

Полные результаты: binary-check.json. Старые LP_Controller, GameRules, Prediction, BoneMatrix отсутствуют. Исходный CCSGoInput-паттерн имеет два совпадения в client.dll; раньше он искался в engine2.dll, которого нет среди присланных бинарников. Старый путь получения углов больше не используется.

## Что осталось

Для полноценной работы нужны восстановление трех обязательных глобальных адресов, проверка схем сущностей, entity-list traversal, костей и GameState (старое поле Prediction+0xA0). В этой версии они не объявлены исправленными. При текущих DLL InitPointers возвращает false: доступны диагностическое окно и журнал, ESP/aimbot не выполняются. Переключать GameReady вручную нельзя считать исправлением.

## Проверки и сборка

9 assertions парсера/сканера прошли под GCC с ASan/UBSan. Все ClCompile-файлы проекта присутствуют. Полная сборка Windows не выполнена.

В x64 Native Tools Command Prompt for VS 2022, из папки проекта:

    msbuild "XAnan CG Intern.vcxproj" /m /p:Configuration=Release /p:Platform=x64

Нужны MSVC v143 и Windows SDK. Python на пользовательском компьютере не нужен.
Журнал: %TEMP%\cs2-internal-startup.log. Из-за закрепления DLL для замены сборки нужен перезапуск процесса.
