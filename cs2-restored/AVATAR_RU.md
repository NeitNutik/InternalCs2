Аватарка в нижней части левой панели меню. Avatar settings: HTTPS image URL + Load / reload. Пустой URL читает %LOCALAPPDATA%\InternalCs2\avatar.png. URL сохраняется в avatar.url рядом с файлом. Для PNG/JPEG декодирование WIC; изображение обрезается по центру до квадрата и масштабируется до 256x256, вывод 96x96 с DPI scale.

Загрузка через системный curl.exe отдельным скрытым процессом из рабочего потока, без shell, TLS-проверка включена, только HTTPS, лимит 8 MiB, 20 секунд, 3 redirects. Сеть и декодирование не выполняются в Present; D3D11 texture создается на render thread. При повторной загрузке предыдущая texture заменяется только после успеха.

Исходный файл картинки из сообщения недоступен в рабочей папке. Точная аватарка не включена. Для завершения нужен PNG/JPG как файловое вложение либо прямая HTTPS-ссылка на изображение. Альтернатива: сохранить нужную картинку локально по указанному пути и нажать Load / reload с пустым URL.
